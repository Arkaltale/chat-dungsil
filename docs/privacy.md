# 챗둥실 개인정보처리방침

시행일: 2026-10-01

챗둥실(이하 "확장")은 치지직·YouTube 라이브 채팅을 보기 편하게 띄우고 조정하는 크롬 확장 프로그램입니다. 이 문서는 확장이 어떤 정보를 다루는지, 어디에 두는지, 어떻게 지울 수 있는지를 설명합니다.

## 요약

- 확장은 어떤 정보도 외부 서버로 보내지 않습니다. 개발자도 사용자의 정보를 받거나 볼 수 없습니다.
- 설정과 모아보기 대상 닉네임은 사용자의 브라우저 안(`chrome.storage.local`)에만 저장됩니다.
- 모아보기로 모은 채팅은 저장하지 않고, 방송 탭의 메모리에만 잠시 보관합니다.
- 광고, 분석 도구, 원격 코드를 사용하지 않으며 정보를 판매하거나 제3자에게 넘기지 않습니다.

## 다루는 정보

| 정보 | 용도 | 보관 위치·기간 |
| --- | --- | --- |
| 채팅창 위치·크기, 투명도, 글자 크기, 잠금, T 모드 자동 분리, 치지직 상단 배너·후원 순위 숨김 설정 | 사용자가 정한 표시 방식을 다시 적용 | 브라우저 안(`chrome.storage.local`). 사용자가 바꾸거나 확장을 제거할 때까지 |
| 모아보기 대상 닉네임(사용자가 직접 입력) | 지정한 사용자의 채팅만 골라 보여 주기 | 브라우저 안(`chrome.storage.local`). 사용자가 목록을 비우거나 확장을 제거할 때까지 |

| 모아보기로 모은 채팅(받은 시각·닉네임·본문) | 모아보기 창에 표시 | 해당 방송 탭의 메모리에만 최대 1,000건. 새로고침, 방송 이동, 탭 종료 시 사라짐. 디스크에 저장하지 않음 |

### 페이지 내용 읽기

확장은 `chzzk.naver.com`과 `www.youtube.com` 페이지에서만 동작합니다. 채팅창 위치를 찾고, 글자 크기를 적용하고, 사용자가 고른 상단 요소를 숨기기 위해 페이지 구조를 읽고 화면 표시를 바꿉니다. 모아보기 수집을 시작하면 화면에 새로 표시되는 채팅의 닉네임과 본문을 읽어, 사용자가 지정한 닉네임의 채팅만 위 표의 방식으로 보관합니다. 그 밖에 페이지 내용을 저장하거나 전송하지 않습니다.

### 외부 PiP 창

외부 PiP 창은 각 사이트가 제공하는 독립 채팅 페이지를 그대로 엽니다. 이때의 통신은 사용자의 브라우저와 해당 사이트 사이에서 이루어지며, 확장이 그 내용을 수집하지 않습니다.

## 권한

| 권한 | 사용 이유 |
| --- | --- |
| `storage` | 위 표의 설정과 모아보기 대상 닉네임을 브라우저 안에 저장 |
| `chzzk.naver.com`, `www.youtube.com` 접근(콘텐츠 스크립트) | 해당 사이트의 채팅창을 띄우고 표시를 조정 |

## 정보 삭제

- 모아보기 대상: 확장 팝업의 「특정 사용자 모아보기」에서 목록을 지우고 저장합니다.
- 모아보기로 모은 채팅: 모아보기 창의 「목록 비우기」를 누르거나 방송 탭을 새로고침·종료합니다.
- 모든 정보: `chrome://extensions`에서 확장을 제거하면 브라우저에 저장된 정보가 함께 삭제됩니다.
