# Chrome 웹 스토어 등록정보 초안

대시보드에 옮겨 적을 내용과 준비물을 모은 문서입니다. 근거는 Chrome 웹 스토어 공식 문서(developer.chrome.com/docs/webstore)이며, 표시가 없는 수치는 공식 문서에서 확인한 값입니다.

## 기본 정보

| 항목 | 값 |
| --- | --- |
| 이름 | 챗둥실 – 라이브 채팅 플로팅 (manifest `name`) |
| 요약 설명 | manifest `description`을 그대로 씀 |
| 카테고리 | 도구(Tools) |
| 언어 | 한국어 |
| 개인정보처리방침 URL | GitHub Pages에 게시한 [privacy.md](privacy.md)의 주소 |

이름에 YouTube·치지직을 넣지 않습니다. Google 상표는 서면 허가 없이 확장 이름에 쓸 수 없고, 호환 표기는 설명에서 "~에서 사용할 수 있는" 형태로만 씁니다.

## 상세 설명

```
치지직·YouTube 라이브 방송에서 사용할 수 있는 채팅창 플로팅 도구입니다. 채팅창을 화면 위에 띄워 원하는 위치와 크기로 봅니다.

■ 채팅창 띄우기
· 극장 모드와 전체화면에서도 채팅창을 띄워 드래그로 옮기고 모서리로 크기를 조절합니다.
· 일반·극장·전체화면 모드마다 위치와 크기를 따로 기억합니다.
· 투명도 조절, 이동·크기 잠금, 잠시 숨기기를 지원합니다.

■ 항상 위 PiP 창
· 채팅을 별도의 작은 창(Picture-in-Picture)으로 분리해 다른 창 위에 띄웁니다.

■ 글자 크기
· 채팅 상단의 −/+ 버튼이나 확장 팝업에서 채팅 글자 크기를 12~24px로 조절합니다.

■ 치지직 전용 기능
· 채팅 상단 배너와 후원 순위를 각각 숨길 수 있습니다.
· 특정 사용자 모아보기: 지정한 닉네임의 채팅만 모아 별도 창에서 봅니다.

■ 개인정보
· 설정과 모아보기 대상 닉네임은 이 브라우저 안에만 저장하고, 어떤 정보도 외부로 보내지 않습니다.

챗둥실은 NAVER(치지직)·Google(YouTube)과 무관한 비공식 도구입니다. YouTube는 Google LLC의 상표입니다.
```

## 개인정보 탭

### 단일 목적

```
치지직·YouTube 라이브 채팅을 보기 편하게 띄우고 표시 방식(위치·크기·투명도·글자 크기·표시 요소)을 조정합니다. 치지직에서는 원하는 사용자의 채팅만 골라 보는 모아보기도 같은 목적(채팅을 보기 편하게)에 포함됩니다.
```

### 권한 사용 근거

| 권한 | 입력할 근거 |
| --- | --- |
| `storage` | 채팅창 위치·크기, 투명도, 글자 크기 등 표시 설정과 모아보기 대상 닉네임을 사용자 브라우저에 저장합니다. |
| 호스트 권한(`chzzk.naver.com`, `www.youtube.com`) | 두 사이트의 라이브 채팅창을 찾아 띄우고, 글자 크기와 표시 요소를 조정합니다. 다른 사이트에서는 동작하지 않습니다. |

### 원격 코드

"아니요, 원격 코드를 사용하지 않습니다"를 선택합니다. 모든 스크립트가 확장 패키지 안에 있습니다.

### 데이터 사용 공개

공식 FAQ에 따르면 기기 밖으로 보내지 않고 로컬에서만 처리해도 공개 대상입니다. 아래는 보수적으로 고른 안이며, 대시보드의 실제 항목 이름을 보고 확정합니다.

| 대시보드 항목(예상) | 체크 | 이유 |
| --- | --- | --- |
| 웹사이트 콘텐츠 | 예 | 채팅창을 찾고 모아보기에서 채팅 본문을 읽음 |
| 개인 커뮤니케이션 | 예 | 모아보기가 다른 시청자의 채팅 메시지를 탭 메모리에 보관 |
| 개인 식별 정보 | 판단 필요 | 사용자가 입력한 다른 시청자의 닉네임을 저장. 닉네임만으로 식별 정보로 볼지 대시보드 설명을 보고 결정 |
| 그 외(건강, 금융, 인증, 위치, 웹 기록, 사용자 활동) | 아니요 | 다루지 않음 |

인증 항목은 세 가지 모두 체크합니다. 데이터를 제3자에게 판매·이전하지 않음, 단일 목적과 무관한 용도로 쓰지 않음, 신용도 판단·대출 목적으로 쓰지 않음.

## 이미지 준비물

| 항목 | 규격 | 상태 |
| --- | --- | --- |
| 확장 아이콘 | 128×128 PNG(그림 96×96 + 사방 16px 투명 여백), 48·16px 권장 | 완료: `icons/icon-{16,32,48,128}.png`(원본 `icons/icon.svg`, 구름 말풍선 표정형) |
| 스크린샷 | 1280×800(또는 640×400), 1~5장, 모서리 직각 | 미제작 |
| 작은 프로모션 타일 | 440×280 PNG/JPEG, 필수 | 완료: `store/promo-small-440x280.png`(원본 `store/promo-small.html`) |
| 마키 타일 | 1400×560, 선택 | 미제작 |

아이콘·타일·스크린샷에 치지직·YouTube 로고를 쓰지 않습니다. 스크린샷은 실제 화면을 변형하지 않고 씁니다.

### 스크린샷 구성안

1. 전체화면 방송 위에 떠 있는 채팅창(이동 바·크기 조절 모서리가 보이게)
2. 항상 위 PiP 창으로 분리한 채팅
3. 채팅 상단 글자 크기 도구와 확장 팝업
4. 특정 사용자 모아보기 창(치지직)

## 게시 전 확인

- 개발자 계정: 등록비 납부, 2단계 인증, 연락처 이메일 인증, 거래자/비거래자 신고. 등록 이메일은 나중에 바꿀 수 없습니다.
- 업로드 zip: `manifest.json`이 최상위에 오고, 런타임 파일만 담습니다(`tests/`, `docs/`, `store/`, `output/`, `.playwright-cli/`, `icons/icon.svg` 등 제외).
- 대시보드에서 YouTube 동영상이 필수 항목인지 확인합니다(공식 문서끼리 표현이 다름).
