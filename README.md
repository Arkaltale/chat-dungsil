# 챗둥실 – 라이브 채팅 플로팅

지원 사이트는 치지직과 YouTube입니다. 극장모드와 실제 전체화면(F키/전체화면 버튼) 양쪽에서 치지직·유튜브 라이브 채팅창을 자유롭게 옮기고 크기를 바꿀 수 있는 크롬 확장. 위치/크기/투명도는 사이트별로 따로 저장됩니다.

> 챗둥실은 치지직(NAVER)·YouTube와 무관한 비공식 도구입니다.

## 설치 (압축해제된 확장 프로그램으로 로드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 → 이 저장소 폴더(`manifest.json`이 있는 폴더) 선택
4. 치지직·유튜브 방송 페이지를 새로고침

이미 로드했다면 `chrome://extensions`에서 새로고침(↻) 버튼을 누른 뒤 방송 페이지를 새로고침하세요. 확장 팝업에서 설치 버전과 페이지 버전이 서로 같은지 확인할 수 있습니다. 다르면 방송 페이지를 새로고침하세요.

## 사용법

macOS에서는 Alt = Option 키입니다.

- **진짜 전체화면(F키) 진입 시 자동으로 채팅창이 플로팅**됩니다. 채팅 UI가 늦게 나타나는 경우에도 전체화면에 있는 동안 계속 감지하다가 나타나는 즉시 띄웁니다. 일반 화면으로 돌아오면 원래 자리(도킹)로 복귀합니다. T 자동 분리를 켰다면 전체화면에서 T 모드로 나와도 유지됩니다. 단축키로 직접 플로팅을 켠 경우에는 화면 모드를 바꿔도 유지됩니다.
- **Alt+Shift+C** — 채팅창 플로팅 켜기/끄기. 켜면 채팅창이 떠오르고, 끄면 원래 자리(도킹 상태)로 복귀
- 플로팅 상태에서 채팅창에 **마우스를 올리면** 상단에 드래그 바, 우하단에 크기조절 모서리가 나타남 (단축키 불필요)
  - 상단 바 드래그 = 이동, 우하단 모서리 드래그 = 크기조절
  - 상단 바의 ⟲ = 위치/크기 초기화, ✕ = 플로팅 해제
- **J** — 치지직 기본 동작(채팅창 활성화/입력 포커스) 그대로. 사이트가 J로 채팅창을 띄우면 자동 감지가 이어받아 플로팅합니다. 채팅을 직접 숨긴 상태에서 J를 누르면 자동 플로팅이 다시 켜집니다
- **Alt+Shift+O** — 채팅 투명도 단계 조절(100% → 80% → 60% → 40% 순환). 반투명 상태여도 마우스를 올리면 일시적으로 불투명해집니다
- **Alt+Shift+R** — 현재 화면 모드(일반/T/전체화면)의 위치·크기 초기화
- **Alt+Shift+P** — 채팅창 수동 지정 모드. 자동 인식이 틀리면 채팅창 영역을 직접 클릭해서 지정
- **툴바 확장 아이콘 클릭** — 설치·페이지 버전과 적용 상태, 플로팅 토글, 위치/크기 초기화, 투명도 설정을 확인합니다. 치지직 자체 채팅 팝업 창에서 열면 채팅 팝업 전용 모드로 글자 크기·상단 배너·후원 순위 숨김과 모아보기만 표시하고, 유튜브 채팅 팝아웃 창에서 열면 글자 크기만 표시합니다. 팝업 맨 아래의 **사용 안내**를 펼치면 주요 기능 요약과 단축키를 볼 수 있습니다(채팅 팝업 전용 모드에서는 단축키를 숨깁니다).
- **T 모드에서 자동 분리** — 팝업에서 사이트별로 켭니다(기본 꺼짐). 자동으로 분리된 채팅은 일반 화면으로 돌아오면 복귀합니다.
- **이동·크기 조절 잠금** — 실수로 채팅창을 옮기거나 크기를 바꾸는 것을 방지합니다. 팝업에서 해제할 수 있습니다.
- **채팅 잠시 숨기기 / 다시 표시** — 플로팅 위치를 유지한 채 채팅을 잠시 가립니다. 팝업에서 다시 표시하세요.
- **채팅 글자 크기** — 팝업에서 일반 채팅의 닉네임·본문을 12~24px로 조절합니다. 사이트별로 저장되며, 기본값 복원 버튼으로 사이트 원래 크기를 적용합니다. 새 메시지와 PiP 채팅에도 적용됩니다. 일반·분리·PiP 채팅창 상단의 −/+/기본 버튼으로도 바로 조절할 수 있습니다. 치지직 자체 채팅 팝업 창과 유튜브 채팅 팝아웃 창에도 같은 버튼을 표시하며, 여기서 바꾼 값은 방송 탭·PiP·확장 팝업과 공유합니다. 치지직 PiP와 채팅 팝업 창에서는 설정이 겹치지 않도록 치지직 자체 채팅 크기(−/100%/+) 버튼을 숨깁니다.
- **상단 배너·후원 순위 숨기기** — 치지직에서 각각 켜고 끌 수 있습니다. 설정은 저장되며 일반·분리·PiP 채팅에 적용됩니다. 채팅 메시지·고정 공지·입력창은 유지합니다.
- **외부 PiP 창 사용** — 팝업에서 켜면 채팅을 별도 PiP 창에 표시합니다. 끄거나 PiP 창의 ✕를 누르면 이전 도킹·플로팅·숨김 상태로 복원합니다. 브라우저가 팝업 클릭으로 실행을 허용하지 않으면 페이지에 표시되는 「외부 PiP 창 열기」 버튼을 누르세요.

위치와 크기는 사이트별 일반/T/전체화면 각각 별도로 저장됩니다. T 모드 위치를 한 번도 저장하지 않았다면 일반 화면 위치를 이어받습니다. 투명도·자동 T 분리·잠금 설정도 사이트별로 저장합니다. 창을 줄이면 채팅창이 화면 안에 들어오도록 임시 보정하고, 창을 다시 키우면 저장된 위치·크기를 적용합니다.

## 치지직 특정 사용자 모아보기

1. 방송 페이지에서 확장 팝업의 **특정 사용자 모아보기**를 펼칩니다. 처음 사용할 때는 닉네임·채팅을 어떻게 다루는지 안내가 표시되며, **확인하고 사용하기**를 눌러야 입력·저장·수집·창 열기를 사용할 수 있습니다. 확인은 한 번만 하면 됩니다.
2. 대상 닉네임을 한 줄에 한 명씩 입력하고 저장합니다. 닉네임은 정확히 일치해야 합니다.
3. **수집 시작**을 누른 뒤 **모아보기 창 열기**로 목록을 확인합니다.

수집을 시작한 이후 화면에 도착한 대상자의 일반 채팅을 수집 시각·닉네임·본문과 함께 표시합니다. 대상 목록만 저장하고, 메시지는 현재 페이지 메모리에 최근 1,000건까지만 보관합니다. 새로고침·방송 주소 변경 시 수집이 중지되고 목록이 비워집니다. 수집 중지는 기존 목록을 남기며, 별도 창의 목록 비우기로 지울 수 있습니다.

모아보기 창에는 자동 스크롤을 끄고 읽는 기능이 있으며, 치지직 글자 크기 설정도 적용됩니다. 같은 방송 탭에서 다시 열면 기존 창을 재사용합니다. 모아보기 창의 **항상 위(PiP)** 버튼을 누르면 목록을 항상 위 PiP 창으로 옮기고, **창으로 되돌리기**나 PiP 창의 ✕로 원래 창에 복원합니다. 브라우저는 PiP 창을 하나만 허용하므로 채팅 PiP와 모아보기 PiP는 동시에 띄울 수 없고, 한쪽을 열면 다른 쪽은 닫히며 원래 상태로 돌아갑니다. 모아보기 창을 닫으면 PiP 창도 함께 닫힙니다.

공개 화면에서 안정적인 사용자·메시지 ID를 얻을 수 없어 닉네임과 화면의 메시지 순서를 기준으로 수집합니다. 닉네임 변경 시 대상을 수정해야 합니다. 시작 전 과거 채팅, 원본 삭제·차단 내역, 유료·특수 채팅의 완전한 동기화는 지원하지 않습니다. 과거로 스크롤하거나 채팅 화면이 통째로 교체되어 신규 여부를 구분할 수 없으면 중복 수집 대신 기준선을 갱신하므로 일부 메시지를 놓칠 수 있습니다. 완전한 방송 채팅 기록 보관 도구는 아닙니다.

## 알려진 제약

- 채팅창은 치지직 `#aside-chatting`·채팅 영역 클래스, 유튜브 `ytd-live-chat-frame`만 자동으로 찾습니다. 사이트 개편으로 자동으로 찾지 못하면 **Alt+Shift+P로 수동 지정**하세요.
- Chrome 116 이상이 필요합니다(외부 PiP에 쓰는 Document Picture-in-Picture).
- 유튜브에서 실제 전체화면에 들어가거나 나올 때 채팅 iframe이 한 번 새로고침될 수 있습니다(1~2초).
- 유튜브 채팅 iframe 안에 입력 포커스가 있으면 페이지 단축키가 전달되지 않을 수 있습니다. 영상 영역을 클릭한 뒤 사용하거나 확장 팝업을 이용하세요.
- J 단축키 연동(숨긴 채팅 재감지)은 치지직 전용입니다. 유튜브의 J(10초 되감기)는 건드리지 않습니다.
- 외부 PiP는 사이트의 독립 채팅 페이지를 새로 여는 방식이라 입력 중이던 문장이나 스크롤 위치는 옮겨지지 않습니다. 원본 방송 탭은 열어 두어야 하며, 방송 주소 변경·새로고침·탭 종료 시 PiP도 닫힙니다.
- PiP 창의 화면 위치는 확장이 지정하지 않습니다. PiP에서는 페이지 안 이동·잠금·숨김 대신 창 자체를 옮기고 크기를 바꾸세요. 다른 앱의 전체화면과 겹칠 때의 동작은 OS·환경에 따라 다를 수 있습니다.

구현 방식과 설계 이유는 [docs/DESIGN.md](docs/DESIGN.md)에, 변경 내역은 [CHANGELOG.md](CHANGELOG.md)에 정리했습니다.

## 개인정보

- 설정(사이트별 위치·크기·투명도·글자 크기·잠금·T 자동 분리·상단 표시 여부, 모아보기 대상 닉네임과 첫 사용 확인 여부)만 브라우저의 `chrome.storage.local`에 저장합니다.
- 모아보기로 수집한 채팅 메시지는 저장하지 않고 현재 방송 페이지의 메모리에 최대 1,000건 보관하며 모아보기 창에 표시합니다. 새 채팅을 가려내려고 채팅창에 표시된 채팅의 사본을 메모리에 두고 비교하며, 이 사본은 다음 비교 때 바뀌고 새로고침·탭 종료 시 사라집니다.
- 어떤 데이터도 외부 서버로 전송하지 않습니다.
- 요청 권한은 `storage` 하나와 치지직·YouTube 페이지 접근(콘텐츠 스크립트)입니다.

자세한 내용은 [개인정보처리방침](docs/privacy.md)을 참고하세요.

## 개발·테스트

빌드 과정은 없으며 저장소 폴더를 그대로 확장 프로그램으로 로드합니다. 회귀 검사는 실제 확장을 headless Chromium에 로드해 실행합니다. `sh tests/run.sh`로 실행하며, 방법과 검사 범위는 [tests/README.md](tests/README.md)를 참고하세요.
